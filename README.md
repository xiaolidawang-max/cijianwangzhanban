# 词间网页版

《雅思词汇真经》的网页版学习工具，收录 22 章、3,623 个词。

[打开词间首页](https://xiaolidawang-max.github.io/cijianwangzhanban/)。顶部可以在单词连播、逐词学习、单词查询和词书与数据之间切换。

## 学习与离线

- [单词连播](https://xiaolidawang-max.github.io/cijianwangzhanban/v30/#continuous) 可同时选中多章。点击章节旁的「下载」可以保存该章图片和录音，之后在已缓存的学习页面离线播放。
- [逐词学习](https://xiaolidawang-max.github.io/cijianwangzhanban/v30/?section=study#chapters) 从章节下方展开词条，可查看配图、释义、搭配和例句。
- [单词查询](https://xiaolidawang-max.github.io/cijianwangzhanban/vocabulary.html) 支持本章搜索、单词发音和全章朗读。
- iPhone 上可以在 Safari 中打开学习页并选择「添加到主屏幕」。

## Windows 桌面快捷方式

1. 在 GitHub 点击 **Code → Download ZIP**，将下载的文件完整解压到你希望长期保存的位置。
2. 双击解压后的 `创建桌面快捷方式.cmd`。
3. 双击桌面上的「词间网页版」，即可用浏览器打开。重启电脑后也可以直接打开，无需安装 Python。

移动词间文件夹后，从新位置再运行一次脚本即可更新快捷方式。也可以直接在文件夹内双击 `vocabulary.html` 打开电脑词表。
